# Wi-Fi Calling Location Gateway — OpenWrt feed

Prebuilt package source for the integrated
[Wi-Fi Calling Location Gateway](https://github.com/smthdagg/wificalling-location-gateway)
package. Two ways to install: a proper opkg/APK **package source** (`src-gz`,
recommended) or a plain **manual download** of the `.ipk`/`.apk`.

## Supported platforms

| Platform | Package |
|---|---|
| Redmi AX6S / mt7622 / AArch64 (cortex-a53) | `wificalling-location-gateway_1.0.0-1_aarch64_cortex-a53.ipk` |
| OpenWrt 24.10 / iStoreOS 24.10 / x86-64 | `wificalling-location-gateway_1.0.0-r1_x86_64.ipk` |
| OpenWrt 25.x / x86-64 | `wificalling-location-gateway-1.0.0-r1.apk` |

## Option A — package source (recommended)

Add the release as a custom source, then install normally:

```sh
# OpenWrt 24.10 / iStoreOS (opkg)
# 1. Import the repository signing key (one-time)
wget -O /etc/opkg/keys/ddf1cd5d87a4b793 \
  https://raw.githubusercontent.com/smthdagg/wificalling-location-gateway-feed/main/wloc.pub

# 2. Add the source and install
echo "src/gz wloc https://smthdagg.github.io/wificalling-location-gateway-feed" \
  >> /etc/opkg/customfeeds.conf
opkg update
opkg install wificalling-location-gateway

# OpenWrt 25.x (apk): use Option B (manual download) for now - the
# APKINDEX for apk v3 repositories is generated by the OpenWrt build
# system's apkindex tool; see scripts/gen-feed-index.sh.
```

> The release directory contains the `Packages` / `Packages.gz` opkg index
> generated by `scripts/gen-feed-index.sh`.

## Option B — manual download

1. Download the asset for your platform from the
   [release page](https://github.com/smthdagg/wificalling-location-gateway/releases/tag/v1.0.0).
2. Verify it against `SHA256SUMS` in the same release.
3. Install:

```sh
opkg install ./wificalling-location-gateway_1.0.0-1_aarch64_cortex-a53.ipk   # AX6S
opkg install ./wificalling-location-gateway_1.0.0-r1_x86_64.ipk              # OpenWrt 24.10 / iStoreOS x86-64
apk add ./wificalling-location-gateway-1.0.0-r1.apk                          # OpenWrt 25.x x86-64
```

## Notes

- Install **over** an earlier component build; do not uninstall the old
  Gateway/WLOC packages first (both UCI configs are conffiles and are kept).
- Required system facilities (not bundled): sing-box, firewall4/nftables,
  `ip-full`, LuCI/rpcd, and the nft TPROXY kernel modules.
- The package provides both application components (`wloc-service`,
  `luci-app-wificalling-location-gateway`, `luci-app-wificalling-gateway`)
  and exposes a single `WifiCalling&Wloc Gateway` LuCI menu.
